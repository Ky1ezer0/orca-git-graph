    Repository Settings
    
    
    
    
    
    
    
      
    
        
    General
    
          
          
          
    Main-panel snapshots live outside the repository. Orca may show the cache folder as a separate workspace. Click a file again to refresh its snapshot.
    
          
          
          
          
          
    Reflogs can include local recovery and checkpoint commits. Nothing is restored or changed.
    
          
        
    
        
    Issue Linking
    
          
    Add a prefix and HTTPS URL for each issue tracker. For example, # matches #123 and PROJ- matches PROJ-123. Prefixes are case-sensitive; {issue} is the number without the prefix.
    
          
    
          
    Use {issue} in each URL, such as https://example.com/browse/PROJ-{issue}. Remove all rules to disable links.
    
        
    
      
    
      
    User Details
    Effective Git identity. Edits and removal affect repository-local overrides only, never global configuration.
    
      
    Remote Configuration
    Changes apply only after confirmation. Removing a remote also removes its remote-tracking references. No automatic network requests.
    
    
    
    
    Changes apply and save automatically per repository.
